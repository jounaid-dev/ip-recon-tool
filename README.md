# IP Recon Tool

A simple and fast Bash script to perform IP adress geolocation and OSINT reconnaissance.

## Installation & Usage

1. Clone the repository or download 'script.sh'.
2. Give execution permissions to the script
   "
   chmod +x script.sh
   "
3. Run the tool:
   "
   ./script.sh
   "

### Features
1.Dynamic user input target selection.
2.Automated API querying using 'curl'.
3.Outputs saved into 'output.txt'.
