# IP Recon Tool

A simple and fast Bash script to perform IP adress geolocation and OSINT reconnaissance.

## Installation & Usage

1. Clone the repository or download 'script.sh'.
2. Give execution permissions to the script
   '''bash
   chmod +x script.sh
   '''
3. Run the tool:
   '''bash
   ./script.sh
   '''

### Features
Dynamic user input target selection.
Automated API querying using 'curl'.
Outputs saved into 'output.txt'.
